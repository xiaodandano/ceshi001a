# 僵尸搜打撤 DEMO

一个融合 **《向僵尸开炮》** 与 **《三角洲行动》搜打撤模式** 核心玩法的网页小游戏 DEMO。
纯 HTML5 Canvas + 原生 JavaScript 实现,零依赖,打开即玩。

## 🎮 玩法融合点

| 来源 | 融合的核心机制 |
| --- | --- |
| 向僵尸开炮 | 火炮**自动索敌开火**,玩家只负责走位;僵尸潮随时间增强;局内搜「军备箱」获得随机火力升级(多管炮、穿甲、射速…) |
| 三角洲搜打撤 | 地图散布物资箱,**靠近自动搜索**;战利品分普通/稀有/史诗/传说四档;收集后前往撤离点**站立 5 秒撤离**;**阵亡掉光、撤离才入库**;仓库资产跨局持久化(localStorage) |

## 🕹 操作

- **PC**:WASD / 方向键移动,空格开始/重开
- **手机**:触屏虚拟摇杆
- 开火、搜索、拾取全部自动 —— 你只需要决定:**继续贪,还是撤?**

## ⏱ 一局流程

1. 出生在地图中央,撤离点在随机角落(HUD 有方向指示 + 小地图)
2. 边打僵尸边搜箱子:高级箱多在地图边缘(风险越大,货越好)
3. 精英僵尸(紫色)必掉战利品
4. 3 分钟后「尸潮风暴」来袭,刷怪翻倍提速 —— 赶紧跑路
5. 撤离成功 → 战利品计入仓库总资产;阵亡 → 本局全丢

## 🚀 运行

无需构建,直接打开:

```bash
# 任选其一
open index.html              # macOS
python3 -m http.server 8000  # 然后访问 http://localhost:8000
```

## 📁 文件结构

```
index.html  — 页面入口
game.js     — 全部游戏逻辑(状态机/战斗/搜索/撤离/渲染/音效)
```
